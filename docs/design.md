# Design — Salary (финансовый аналитик)

Документ описывает визуальный язык приложения. Основан на ответах на 10 вопросов по дизайну.

## 0. Итоги опроса

| # | Вопрос | Решение |
|---|--------|---------|
| 1 | Цветовая тема | Светлая + тёмная, по умолчанию — системная, есть переключатель |
| 2 | Акцентный цвет | Индиго / синий |
| 3 | Стиль | Минимализм: много воздуха, тонкие границы, почти без теней |
| 4 | Навигация | Боковое меню слева (десктоп), нижняя панель (мобильный) |
| 5 | Главный график расходов | Горизонтальные столбцы, отсортированные по убыванию |
| 6 | Дашборд | KPI-карточки сверху, графики ниже |
| 7 | Шрифт | Inter (с `tabular-nums` для сумм) |
| 8 | Скругления | Средние: 8px (кнопки, поля), 12px (карточки) |
| 9 | Категории | Линейная иконка Lucide в цветном круге |
| 10 | Анимация | Тонкая: 150–250 мс, плавное появление графиков |

---

## 1. Принципы

1. **Цифры — главное.** Суммы крупные; в столбцах и таблицах — цифры одинаковой ширины (`tabular-nums`) и выравнивание по правому краю. Крупные одиночные числа (KPI) — обычными пропорциональными цифрами: моноширинные на большом кегле выглядят «рыхло».
2. **Тишина интерфейса.** Цвет используется только для смысла: акцент (действие), доход (зелёный), расход (красный), категории (палитра).
3. **Одна задача — один экран.** Никаких перегруженных панелей.
4. **Доступность.** Контраст текста ≥ 4.5:1, фокус виден всегда, цвет никогда не единственный носитель смысла (рядом знак `+`/`−` и подпись).

## 3. Типографика

Шрифт: **Inter** (через `next/font/google`, subsets `latin`, `cyrillic`).

| Роль | Размер / межстрочный | Вес | Пример |
|------|----------------------|-----|--------|
| Display (KPI-сумма) | 32 / 40 | 600 | `245 300 ₽` |
| H1 (заголовок страницы) | 24 / 32 | 600 | «Дашборд» |
| H2 (заголовок карточки) | 18 / 28 | 600 | «Расходы по категориям» |
| Body | 14 / 20 | 400 | Текст, ячейки таблиц |
| Small / Caption | 12 / 16 | 500 | Подписи осей, лейблы KPI |

- Суммы в списках и таблицах: `tabular-nums`; KPI-значения — без него. Разделитель тысяч — неразрывный пробел, формат через `Intl.NumberFormat('ru-RU', { style: 'currency', currency })`.
- Доход отображается со знаком `+`, расход — со знаком `−` (U+2212).

## 4. Сетка, отступы, скругления

- Шкала отступов: 4 / 8 / 12 / 16 / 24 / 32 / 48 px.
- Контейнер контента: max-width 1280px, внутренние поля 24px (десктоп), 16px (мобильный).
- Сетка дашборда: 12 колонок, gap 16px (мобильный) / 24px (десктоп).
- Скругления: `--radius-sm: 6px` (бейджи), `--radius: 8px` (кнопки, поля), `--radius-lg: 12px` (карточки, модалки).
- Тени: только у всплывающих элементов (dropdown, dialog, toast) — `0 8px 24px rgb(0 0 0 / 0.08)`. Карточки — только граница `1px var(--border)`.

## 6. Навигация (сайдбар)

Пункты меню (иконки Lucide):

1. `LayoutDashboard` — Дашборд
2. `ArrowLeftRight` — Операции
3. `Tags` — Категории
4. `PiggyBank` — Бюджеты
5. `BarChart3` — Аналитика
6. `Settings` — Настройки

Внизу сайдбара: аватар пользователя, переключатель темы (`Sun`/`Moon`/`Monitor`), выход.

Активный пункт: фон `--primary-soft`, текст и иконка `--primary`, слева полоска 3px.

### 7.3 Операции
- Фильтры сверху: период, тип (доход/расход), категория, поиск.
- Таблица (десктоп): дата · категория (иконка+название) · описание · сумма (справа). Мобильный — список карточек, сгруппированных по дням.
- Добавление/редактирование — в боковой панели (Sheet) справа на десктопе, полноэкранный Drawer снизу на мобильном.

### 7.4 Категории
- Две вкладки: «Расходы» / «Доходы». Плитка категорий: иконка, название, сумма за месяц.
- Создание: название, тип, иконка (picker из ~40 Lucide-иконок), цвет (8 из палитры).

### 7.5 Бюджеты
- Список категорий с прогресс-баром «потрачено / лимит».
- Цвет полосы: < 80% — `--primary`, 80–100% — `--warning`, > 100% — `--expense`; дорожка — светлый шаг того же цвета. Статус всегда с иконкой и подписью: «В норме», «Близко к лимиту», «Превышен».
- Ниже — список «Без бюджета» с тратами за месяц и кнопкой «+ Лимит».


### 7.5a Уведомления о бюджетах
- Колокольчик (`Bell`) внизу сайдбара над профилем (на планшете — только иконка) и в шапке телефона рядом с аватаром. Счётчик непрочитанных — красный кружок с числом (99+).
- Список: заголовок «Уведомления», «Отметить все»; пункт — иконка статуса (`TriangleAlert` янтарный для 80%, `CircleAlert` красный для превышения), заголовок «Бюджет «Кафе»: потрачено 90 %» / «Бюджет «Кафе» превышен», строка «4 500 ₽ из 5 000 ₽ · Ноябрь 2026», дата. Непрочитанные — жирным и с точкой `--primary`.
- Сразу после сохранения — всплывающее сообщение (8 с) с кнопкой «Открыть» → бюджеты месяца. Иконка сообщения в цвете статуса.
### 7.6 Аналитика
- Выбор периода (месяц / квартал / год / произвольный).
- Графики: тренд расходов по месяцам (линия), структура расходов (горизонтальные столбцы), сравнение с прошлым периодом, топ-5 крупнейших трат.

## 8. Графики (Recharts)

| График | Тип | Правила |
|--------|-----|---------|
| Расходы по категориям | Горизонтальные столбцы (HTML) | Сортировка по убыванию; не больше 8 столбцов: топ-7 + «Остальные (N)»; сумма у конца столбца, доля — в подсказке и таблице. **Все столбцы одного цвета `--chart-bar`**: это один ряд с категориями без порядка, цвет по категориям лишь дублировал бы длину столбца. Категорию узнают по подписи и иконке в цвете категории |
| Доходы vs расходы | Сгруппированные вертикальные столбцы + линия баланса (Recharts) | `--chart-income`, `--chart-expense`, `--chart-balance`; одна ось Y (все ряды в одной валюте); легенда над графиком; подсказка показывает все три значения месяца |
| Тренд по месяцам | Линия / area с градиентом 15%→0% | Точки только на hover |
| Норма сбережений | Прогресс-бар | Цвет `--primary` |
| Накопленные расходы (аналитика) | Две линии | Приём «выделение»: текущий период `--chart-bar`, прошлый — серый `--chart-previous` (#64748B); текущая линия обрывается на сегодняшнем дне |
| Динамика расходов (аналитика) | Area: линия 2px + заливка 10% | По дням до 2 месяцев, длиннее — по месяцам; будущие дни/месяцы не рисуются |

Реализация: «Доходы vs расходы» на дашборде — Recharts, загружается отдельно и только когда график близко к экрану. Графики аналитики (динамика, накопленные расходы) — лёгкий собственный SVG-компонент `components/charts/line-chart.tsx` с теми же правилами: линии 2px, заливка 10%, сплошная сетка, подсказка с вертикальной линией по всем рядам, управление стрелками ←/→, Home/End.

Общие правила:
- Сетка: только горизонтальные линии, цвет `--border`, **сплошные** (пунктир читается как «прогноз» или «порог»).
- Столбцы не толще 24px (у нас 16px в паре и 12px в горизонтальных), скругление 4px только на конце, у основания — прямой угол; между столбцами пары — зазор 2px.
- Точки линии: радиус 4px с кольцом 2px цвета фона.
- **Цвета графиков** проверены валидатором палитры (яркость, насыщенность, различимость при дальтонизме, контраст с фоном карточки). Светлая тема: доходы `#059669`, расходы `#DC2626`, баланс/столбцы `#4F46E5`. Тёмная тема — свои шаги, а не автоматическая инверсия: `#059669`, `#EF4444`, `#6366F1` (более светлые оттенки выходят за допустимую яркость на тёмном фоне).
- Оси: шрифт 12px, цвет `--muted-foreground`, суммы сокращаются (`45K`, `1,2M`).
- Тултип: карточка `--surface`, граница, скругление 8px, сумма полностью.
- Скругление столбцов: 4px на конце.
- Пустое состояние: иллюстрация-иконка + текст «Нет данных за период» + кнопка «Добавить операцию».
- Все графики имеют альтернативу — таблицу (кнопка «Показать как таблицу») для доступности.

## 9. Компоненты (shadcn/ui)

Button, Input, Select, Dialog, Sheet, Drawer, DropdownMenu, Tabs, Table, Card, Badge, Calendar/DatePicker, Toast (Sonner), Skeleton, Progress, Avatar, Tooltip.

Варианты кнопок: `default` (индиго), `secondary` (surface + граница), `ghost`, `destructive`. Высота: 36px (default), 32px (sm), 40px (lg).

## 10. Анимация

| Элемент | Эффект | Длительность / easing |
|---------|--------|-----------------------|
| Hover кнопок, строк | Смена фона | 150 мс, `ease-out` |
| Открытие Sheet/Dialog | Slide/fade | 200 мс, `cubic-bezier(0.32, 0.72, 0, 1)` |
| Появление графиков | Рост столбцов от 0 | 250 мс (Recharts `animationDuration`) |
| Загрузка данных | Skeleton с pulse | — |
| Toast | Slide снизу | 200 мс |

`@media (prefers-reduced-motion: reduce)` — все анимации отключаются.

## 11. Состояния

- **Loading:** Skeleton-заглушки по форме контента (не спиннеры).
- **Empty:** иконка 48px `--muted-foreground`, заголовок, одна строка пояснения, основная кнопка.
- **Error:** inline-сообщение под полем (`--expense`, 12px); глобальные ошибки — Toast.
- **Success:** Toast «Операция добавлена» с кнопкой «Отменить» (5 сек).

## 12. Иконки и тон текста

- Иконки: Lucide, stroke 1.75, размер 16 (в тексте) / 20 (в меню) / 24 (в пустых состояниях).
- Тон: дружелюбный, короткий, на «вы». Кнопки — глаголы («Добавить», «Сохранить»).
